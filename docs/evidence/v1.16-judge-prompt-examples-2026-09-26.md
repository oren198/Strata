## 3. Findings

1. **The judge's conduct/interior boundary is unstable.** On the unchanged base prompt, conduct is
   misread as manufactured attribution 13–25% of the time, depending on the run and its provider
   mix. Per item, the same prompt swings widely: `j4-827-d` scored 10/20 in one run, and 6/20 in
   another.
2. **Interior assertions about another scope get admitted through an invented informant (#225).**
   On the base prompt, "payroll-ops only processes overtime claims filed before the 20th of the
   month" (`j4-833`) was admitted in **20/20** reps. Every admit went through the hearsay path with
   an informant the judge made up: the contributor's own role ("informant 'skill=eng-lead
   scope=s_fleet_dispatch'"), or the other scope named as its own informant. `j4-832` ("legal-review
   has a rule that…") was admitted in 2/20 the same way. `j4-834` ("apparently lab-safety has
   decided…") was declined 20/20.
3. **Prompt-text fixes on this boundary do not hold across provider mixes.** Unpinned measurements
   cannot gate wording. Further prompt work on this line is frozen until gates run on a
   provider-pinned judge (#224).

while every fake-judge test had passed.

eval gap was also closed: p5-01 now scores the issuer's own verdict.
