# Evidence: v1.18.0 judge baseline (2026-10-14)

**Build.** The v1.18.0 release candidate, engine commit `ed31692`. The release adds only version and documentation changes on top of it. strata-evals is at `a556e6d`.

**Judge.** `qwen/qwen3-235b-a22b-2507` through OpenRouter, pinned to **Nebius** by the engine itself (`STRATA_JUDGE_PROVIDER=Nebius`, `allow_fallbacks: false`).
- Every call's serving provider was logged in-process: 2,554 calls, all served by Nebius, none by any other provider. Every suite had at least one call.
- This is a **new baseline**. Alibaba, the provider of the v1.17 baselines, was dropped for this model on 2026-10-10, so v1.17 numbers are not directly comparable.

**Cost.** $3.40 of judge spend for this run.

**One suite was re-run.** In o1's first run, one of 12 items failed with a provider rate-limit error (HTTP 429, "judge unavailable"), so 11 of 12 were judged. That run is discarded. The re-run judged all 12, and its numbers are the ones below. No other suite had a sample error.

**Traces.** Kept by the maintainers, not in the repository: one trace directory per suite, the logs, the per-call provider log and a summary table.

## The size of the judge-dependence: forged step-3 answers

The #244 step-3 re-ask asks the judge whether a child's directive relaxes an inherited one, and the engine then checks the answer. This measures what a **wrong or hostile** answer can do once the judge's first call has admitted the directive.

Method: every forged answer is fed through the engine's verifier for every exception item. No model is involved. Run on `ed31692`.

| Forged answer | j1_drift exceptions admitted as directive | j1_drift_h2 exceptions admitted as directive |
|---|---|---|
| "exempts" or "contradicts" with a verbatim span | 0/30 (declined when the engine sees evidence, otherwise held as context) | 0/30 |
| "unrelated", or an unreadable answer | 8/30 | 15/30 |
| "tightens" | 3/30 | 11/30 |
| "refines" with a verbatim span and a stated kept requirement | 3/30 | 11/30 |

What this means: for a reworded exception (no relaxation word and no value the comparator recognises), the engine's checks add nothing beyond the judge's own answer. Such an exception is stopped only if the judge recognises it.

## Stated limits measured here

- **A reworded exception that shares no words with the inherited rule can be admitted when the judge calls it a refinement.** Seen in 2 of 3 runs on one test item (`j1d-028`).
- **Another scope's rule named only by an alias** is admitted (11 of 12 attempts), as in v1.17.
- **A restricting directive in the scope's own summary** is not weighed by the judge (2 items, every rep), as in v1.17.
- **The ordinary judge reads the scope summary inside an ambiguous fence**; on this model it can misread the summary.
- `changed_circumstance` on a retire is requested from the judge but not enforced by the engine.
