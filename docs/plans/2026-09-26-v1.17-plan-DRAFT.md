# Plan (DRAFT): v1.17

**Status:** draft, written during the post-1.16 release freeze. It needs CEO approval. Nothing
here merges to a release branch or tags until the operator lifts the freeze. Work runs on
branches only.
**Base:** main `7130ac5` (1.16.0).

## Standing rules (from v1.15–v1.16)

1. A verdict goes in `decision`; an invariant the theory states is enforced by the engine. Never
   hang behaviour on an optional judge field.
2. A design note comes before code, for every engine change, and the architect approves it.
3. The proof that a judge-input change caused no regression is **input identity**: capture fixtures
   from the base first, and pin every untargeted render. J1 and J4 are noise context.
4. Judge prompts carry placeholders, not concrete worked examples. No eval item shares a prompt's
   domain, name or phrasing.
5. Gates are pooled over a class. n is chosen from the measured SD, so that the floor sits at
   ≥2.8 SE or more, and results are reported as a rate with both counts.
6. **Every live gate runs pinned** to one OpenRouter provider (Alibaba, request-level, evals-side;
   a pin violation fails the run). The first pinned gate for any metric is a **new baseline**, not
   comparable to the unpinned 1.15–1.16 numbers without saying so.
7. Live-shape tests replay a real captured judge response through the real path (releasing
   item 13). The strata-evals mechanical suite runs on every merged tree (item 12).
8. The philosopher checks contract lines before code, for any change to what the judge rules on.

## Post-freeze release step: the MCP Registry listing (confirmed 2026-09-26)

The registry verifies PyPI ownership by checking the **PyPI package README** (the uploaded long
description) for `mcp-name: io.github.oren198/strata`. A file in the GitHub repo does not satisfy
it. Source: modelcontextprotocol/registry, docs/modelcontextprotocol-io/package-types.mdx,
"Ownership Verification". strata-mem 1.16.0 lacks the marker, so the listing waits for the first
post-freeze release. There will be no 1.16.1 during the freeze (CEO).

In that release:
- Add `<!-- mcp-name: io.github.oren198/strata -->` to README.md, on its own line.
- Commit `server.json` at the repo root:
  - schema `https://static.modelcontextprotocol.io/schemas/2025-12-11/server.schema.json`;
  - name `io.github.oren198/strata`;
  - one `packages[]` entry: `pypi`, `strata-mem`, `stdio`, with the environment variables.
- After PyPI publishes: `mcp-publisher login github`, then `mcp-publisher publish`. This is the
  operator's step.
